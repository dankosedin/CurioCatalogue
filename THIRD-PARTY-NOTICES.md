# Third-party notices

The mod zip contains one third-party library besides the game's own. Its licence requires this notice to travel with it.

## ExhaustiveMatching (`ExhaustiveMatching.dll`)

Marks a `switch` over a closed set of record types, so that a missed case is a compile error
(`docs/development.md`, "Exhaustive switch"). Only the attributes and the exception it provides are used at run time.
Source: https://github.com/WalkerCodeRanger/ExhaustiveMatching (NuGet package `ExhaustiveMatching.Analyzer`).
