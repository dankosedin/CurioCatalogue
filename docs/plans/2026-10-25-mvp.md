## Stage 10. Public repository and release 0.1.0

Goal: a public GitHub repository where a new team member (also working with AI) can start on a feature right away; the mod's
ModDB page built from the repository's files. The author's requirements, 27.10.2026.

### 10.1 Research
- [x] **ModDB page format.** The description is HTML (field `text` in the API), no Markdown. No import from GitHub; API v2
      (github.com/anegostudios/vsmoddb) cannot edit the description, and creating a release is "Not implemented": page and zip
      are updated by hand. Images can be linked from raw GitHub. Path: README.md → the HTML GitHub renders → the ModDB editor's
      code mode; keep README simple (headings, lists, images). AI: breaks no rules, there is no "made with AI" field; players can
      hide mods after N "low effort" reports. The thanks for AI help stays (the author's decision).
- [x] **Game DLLs in CI.** `api.vintagestory.at/stable.json` gives URLs and md5; `vs_server_linux-x64_1.22.7.tar.gz` (51 MB, no
      account) has all five DLLs we need (with `Lib/protobuf-net.dll`, `Lib/Newtonsoft.Json.dll`), byte for byte the client's.
      The site's terms say nothing about downloading; downloading from the public CDN in CI is not distribution, minimal risk
      (agreed with the author). No DLLs in git (the projects take `$(VINTAGE_STORY)/Lib`). Cache with `actions/cache` by game
      version, read from `modinfo.json`. Risk: tests have run only on Windows; if they fail on Linux, use `windows-latest` and
      `vs_server_win-x64`.
- [x] **Licences.** vsapi/vssurvivalmod READMEs: "all rights reserved", do not redistribute unchanged, but "use it as a basis for
      mods"; the site's terms allow fan art based on the assets. The mod template (anegostudios/vsmodtemplate: CakeBuild, csproj,
      build.ps1) is CC0. Vanilla-derived files in the repo: `shapes/item/book.json`, `modicon.png`, `tools/modicon-source.png`,
      the tapestry piece list in `TapestryPiecesTests.cs`: allowed, but not under our licence, so a separate sentence in
      LICENSE/README ("© Anego Studios, on their terms for mods"). Our textures are drawn by our script; `game:` references are
      not copies. No DLLs in git; NuGet packages are not committed.
- [x] **GitHub rulesets.** Free for public repositories, personal accounts included. For `main`: require a pull request (squash
      only; 0 approvals while the author works alone), linear history, block force pushes, restrict deletions, required status
      checks; empty bypass list. Merge queue needs an organisation, so strict "Require branches to be up to date before merging"
      (the "Update branch" button, with rebase); CI on `pull_request` runs on the merge result with `main`. Personal account; the
      repo can move to an organisation later.
- [x] **Old Claude transcripts** searched for architecture decisions and rejected alternatives: summaries in `notes/decisions/`
      (git-ignored). Stages 1–2 are missing (that session ran on claude.ai/code); their sources are the archived docs and git.
