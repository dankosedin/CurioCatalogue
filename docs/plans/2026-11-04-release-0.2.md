# Release 0.2: review, texts, checks, release

Started 04.11.2026. `ROADMAP.md`, 0.2, item 8: what comes after the features of 0.2 (items 1–7) and before the release.
The steps wait for the end of 0.2; the means for the description and the shots are built earlier, in
`2026-11-04-mod-description.md` (G).

## How to work on this plan

As in the previous plans: one step per short session with the project skill `/step <id>` (`.claude/skills/step/`). Each step
says **Branch**, **After**, **Model**, **Author** (a decision or in-game work only the author can do; "none" means the session
goes ahead on its own) and **Done when**. A session that stops in the middle writes one line under "Where we stopped".

The agent does not run the game and publishes nothing: pushes, the release, the ModDB page and the gallery are the author's,
after a "yes" to the exact text (global rule). A fix found by R1, R4 or R5 is a line under that step, done on its own `fix/*`
branch with a test, a case in `functional.md` and a `CHANGELOG.md` line; a fix too big for a line becomes a step of its own
(R7, …).
